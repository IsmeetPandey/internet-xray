# Contributing

Thanks for helping improve Internet X-Ray.

## Development

1. Fork or clone the repository.
2. Create a focused branch for your change.
3. Install the Python dependencies from `requirements.txt`.
4. Install the Playwright Chromium browser when working on browser analysis.
5. Run the test suite with `pytest -q`.
6. Keep changes focused and update documentation when behavior changes.

## Pull requests

Please explain what changed, why it changed, and how you tested it. Small, reviewable pull requests are preferred.

## Safety

Internet X-Ray is intended for public HTTP(S) resources you are authorized to inspect. Do not use it to bypass authentication, CAPTCHAs, paywalls, or access controls.
